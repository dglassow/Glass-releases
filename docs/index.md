# Documentation Index

Use this file to map a task to the relevant project instructions before doing the work.

| Task area | Read | Use when | Resources covered |
| --- | --- | --- | --- |
| Repository workflow | `docs/repository-guidance.md` | Any task that reads, edits, documents, tests, or prepares changes in this public repository. | Git status, public-repo hygiene, docs maintenance. |
| Change management | `docs/change-management.md` | Any task that changes files, creates commits, creates branches, pushes changes, opens PRs, or prepares releases. | Release-based branch naming, required PR review, commit/push expectations. |
| Deployment workflow | `docs/deployment-guidance.md` | Any task involving GitHub Actions, deploy automation, public content delivery, or merge-to-main behavior. | Main-branch deployment, AWS deployment expectations, required safeguards. |
| Secrets and AWS access | `docs/aws-guidance.md` | Any task involving `.env`, AWS credentials, AWS CLI, IAM identity, Route 53, ACM, CloudFront, S3, or other AWS services. | AWS CLI credential mapping, secret handling, approval boundaries. |
| Domains and DNS | `docs/domain-plan.md` | Any task involving domain selection, registration, hosted zones, DNS records, certificates, docs URLs, release URLs, or support URLs. | Route 53, Route 53 Domains, RDAP checks, ACM follow-ups. |

If a task spans multiple areas, read each relevant doc before making changes.
